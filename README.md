# FixMyCampus | Smart Issue Tracker

FixMyCampus is a Java-based web application designed to help students report and track campus issues such as maintenance problems and other campus-related complaints.

## Features

- Student registration and login
- Report campus issues
- Enter issue details such as title, category, location and severity
- Store complaint information in a MySQL database
- Web-based user interface
- Complaint management and tracking, according to implemented features

## Technologies Used

- Java
- Jakarta EE 10
- Servlets and JSP, where implemented
- HTML, CSS and JavaScript
- MySQL
- JDBC
- Apache Tomcat 10
- NetBeans IDE
- Maven

## Project Setup

1. Clone or download this repository.
2. Open the project in NetBeans.
3. Create a MySQL database named `fixmycampus_db`.
4. Run the database table creation SQL scripts included in the project, if provided.
5. Configure the database connection in `DBConnection.java` with your local MySQL username, password and database settings.
6. Ensure the MySQL Connector/J dependency is available.
7. Build the project using NetBeans.
8. Run the application on Apache Tomcat 10.
9. Open the application in your browser using the local URL shown by NetBeans.

## Database Configuration

Update the database connection settings for your own computer. Do not upload real database passwords or private credentials to GitHub.
